TaskDeck

TaskDeck is a native macOS productivity and daily planning application that brings your Google Tasks and Google Calendar events into a single, unified desktop workspace.

Application Purpose

The primary purpose of TaskDeck is to help users manage daily tasks and schedule time blocks visually. By integrating with Google Tasks and Google Calendar APIs, TaskDeck allows users to view, create, edit, organize, and complete tasks alongside their scheduled calendar events directly from their Mac.

Google API Integration & Data Usage

TaskDeck accesses Google Tasks and Google Calendar API scopes solely to synchronize your personal task lists and calendar entries. All user data, OAuth authentication tokens, and cached items are stored locally on your device using macOS Keychain and local encrypted storage. TaskDeck does not transfer, track, share, or sell user data to external servers or third parties.
